# Optional vision transcription

Vision transcription is disabled by default. To enable the option, configure `VISION_PROVIDER=ollama`, a root `OLLAMA_BASE_URL`, and `OLLAMA_VISION_MODEL` for a separately installed vision-capable Ollama model, then restart the API and worker together. A patient must explicitly choose the option when requesting PDF or image processing; the UI shows the service URL and model. The request is bound to the displayed configuration so changed worker settings fail the job instead of silently sending to a different service.

For local Qwen3-VL 4B, run `ollama pull qwen3-vl:4b`, set `OLLAMA_VISION_MODEL=qwen3-vl:4b`, and use `OLLAMA_BASE_URL=http://host.docker.internal:11434` with Docker Desktop. Keep Ollama running on the host. This vision model is separate from the optional assistant chat and embedding models.

The worker sends at most the first three page images, normalized and reduced to 1600 pixels on the longest side, to the configured service. The job records the model and whether later pages were omitted. Vision output and warnings are separate, unverified page layers. They do not feed structured transcription, document summaries, assistant context, or medical-image interpretation. Clinicians can compare the output with the original and enter corrections in the structured review. Input is capped at 12 MB per model call, response at 1 MB, model calls at 45 seconds, and the existing overall parsing timeout is 180 seconds. If the provider fails or output validation fails, processing fails; retrying invokes the provider again.

The service receives the images and may retain them. Use synthetic data and a provider authorized to receive the data. A model can fabricate text, follow embedded instructions, omit information, or misread images despite the prompt and validation. No model confidence or clinical safety claim is made. Output and prior sends cannot be recalled if access changes during processing; deletion removes the stored page layers but not provider copies, backups, or previously shared material. The service model name is recorded but is not an immutable model identity. DOCX vision is unsupported. No external provider is called by default.
